# Reconciliation Form - Unclaimed Account Ledger

## Overview
Ek naya "Reconciliation" form banana hai jo `Admin.UnclaimedAc` ka ledger dikhata hai. Left side mein saari debits, right side mein saari credits. Har row ke saath checkbox hoga reconciliation ke liye.

## Files to Create

### 1. `src/Pages/Reports/Accounts/Reconciliation/Reconciliation.jsx` (Filter Form)
- `ReportPageLayout` wrapper with title "Reconciliation"
- Date range inputs (startDate / endDate)
- Quick Select (Custom / YearToDate / MonthToDate) - same pattern as Genrallager.jsx
- Submit button - opens popup with `getDataFundtion`

### 2. `src/Pages/Reports/Accounts/Reconciliation/ReconciliationPopup.jsx` (Main View)
- API call: `GernalLager?startDate=...&endDate=...&Account=${Admin.UnclaimedAc}&Store=`
- Data processing same as GenrallagerPopup (opening balance, running balance)
- Split data into: `debits` (Debit > 0) and `credits` (Credit > 0)
- **Two-column layout:**
  - Left column: Debit entries table (checkbox, date, voucher, description, debit amount)
  - Right column: Credit entries table (checkbox, date, voucher, description, credit amount)
- Each row has a checkbox for reconciliation
- Footer: total debit vs total credit, difference
- State: `selectedDebits` and `selectedCredits` arrays tracking checked rows

## API & Data Flow

```
Admin.UnclaimedAc (from Redux: state.AdminReducer.AdminReducer)
        ↓
getDataFundtion(`GernalLager?startDate=${start}&endDate=${end}&Account=${UnclaimedAc}&Store=`)
        ↓
Response: array of { VoucherDate, VoucherNumber, Debit, Credit, Narration, Type, ... }
        ↓
Split: debits[] = items with Debit > 0, credits[] = items with Credit > 0
        ↓
Render: Two side-by-side tables with checkboxes
```
