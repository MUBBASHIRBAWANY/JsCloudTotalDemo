# JSERP

Order-booker app for Jaffar Sons. An order booker signs in to either the Cloud server or the SND server, then works a route from the phone: customers, sale orders, day summary, and attendance.

The app is Expo SDK 58 with Expo Router, React Native 0.88, and Redux. Routes live in `src/app/`.

## Screens

| Route | What it does |
|---|---|
| `/` | Login. Choose **SND** or **Cloud**, then sign in with the order-booker id and password. |
| `/home` | Party list returned by login. Pending customers stay visible until they are sent. |
| `/add-customer` | New customer form. The row is saved on the phone first. |
| `/sales-order` | Orders already on the server, plus orders still waiting on the phone. **Send pending** uploads customers, then orders. |
| `/distributor-sale-order` | Order form for one party, including photos. Opened from Home or Sales Order. |
| `/day-summary` | Sales, outlets, and a 7-day trend for the signed-in order booker. |
| `/attendance` | Mark In and Mark Out with a photo, GPS, date, and time. |
| `/logout` | Sends anything still waiting on the phone, then clears the session. |

A new customer or order is posted only from **Send pending** or **Logout**. A failed send leaves that row on the phone.

## Requirements

- Node.js and npm
- The Cloud API listening on port **3001**
- The SND API listening on port **3005**
- For a physical phone: the phone and the PC on the same Wi-Fi, and Windows Firewall allowing inbound TCP **3001** and **3005**

`localhost` on a phone is the phone itself. The native client uses the host from Expo's `hostUri`. If that host is missing, it falls back to `192.168.10.94`. Change that fallback in `src/api/ApiInstance.jsx` and `src/api/SNDApiInstance.jsx` when the PC address changes. The web client uses `http://localhost`.

## Run

```bash
npm install
npx expo start
```

Open the dev server URL in Expo Go, or press `w` for web. Web login reaches `localhost`. A phone reaches the PC address described above.

Other scripts in `package.json`:

```bash
npm run android
npm run ios
npm run web
npm run lint
npx tsc --noEmit
```

`ios/` and `android/` are not in this repo. Native projects are generated by Expo when you run a build. Do not add those folders by hand.

## API

Login chooses the client. Both clients send JSON through Axios. Photo uploads (attendance and sale orders) use `XMLHttpRequest` and leave `Content-Type` unset so the multipart boundary is set by the device.

| | Cloud | SND |
|---|---|---|
| Base URL | `http://<host>:3001/` | `http://<host>:3005/` |
| Client | `src/api/ApiInstance.jsx` | `src/api/SNDApiInstance.jsx` |
| Login | `POST /DitriButorOrderBooker/login2` | `POST /OrderBooker/OrderBookerLogin3` |
| Session check | `POST /DitriButorOrderBooker/profile` | `POST /OrderBooker/OrderBookerProfile` |
| Add Customer lists | `GET /City` | `GET /OrderBooker/OrderByvendor/:distributorId` or `GET /OrderBooker` |
| Send customer | `POST /Distrbutor` | `GET /Customor/lastCutomer`, `POST /Customor`, then confirm with `GET /Customor/lastCutomer` or `GET /Customor/AllCutomerByDis/:distributorId` |
| Send order | `POST /DistributorSaleOrder` (multipart) or `POST /saleOrder/MobileCreateSaleOrder` (JSON) | `POST /saleOrder/MobileCreateSaleOrder` (multipart) |
| Order list | `GET /saleOrder/getDataByOrderBooker/:orderBookerId`, then `GET /saleOrder/saleOrderByDis/:distributorId` if that list is empty | same paths on port 3005 |
| Day summary | `GET /DistributorSaleOrder/daySummary` and `GET /DistributorSaleOrder/dayTrend` | `GET /saleOrder/daySummary` and `GET /saleOrder/dayTrend` |
| Attendance | `POST /Attandance` (multipart, field `image`) | `POST /Attandance` (multipart, field `image`) |

Day summary on Cloud, and attendance on both servers, send `Authorization: Bearer <OrderBookerToken>`. The attendance path is spelled `Attandance`.

The phone does not upload to Cloudinary. The backend stores the photo.

## Project layout

```
src/app/            Expo Router screens
src/api/            Axios clients, CRUD helpers, attendance upload
src/lib/            Customer form, pending send, sale-order payload
src/hooks/          Session hook (useLoginUser)
src/redux/          Parties, products, and the signed-in user
src/components/     Drawer and shared UI
assets/             Icons and splash
```

`@/` maps to `src/`. `oldCode/` is an earlier copy of the app and is excluded from TypeScript.

## Permissions

The app asks for the camera and photo library for attendance and order photos, and for location while the app is in use for attendance and sale orders. Those strings are set in `app.json`.
